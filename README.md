The repository contains two task for building Convolutional Neural Networks (CNN) in PyTorch.

Code for both tasks was written and tested in Google Colab. 

The first task is about creating CNN neural network for recognizing cats and dogs images. I used AlexNet neural network.

The second task is about fine-tuning pre-trained AI model. You had to use the built-in in PyTorch model inception_v3 and fine-tuned it to recognize pizza and not pizza images. This task was harder for me.
